# Prueba práctica de React

Pequeña aplicación hecha con React, TypeScript y Vite. Muestra una lista de productos obtenida de [dummyjson](https://dummyjson.com/products?limit=20), permite filtrarlos por nombre, marcarlos como favoritos y añadirlos a un carrito.

## Requisitos

- Node.js 20 o superior
- npm

## Cómo arrancar

```bash
npm install
npm run dev
```

Abre la URL que muestra la terminal (por defecto `http://localhost:5173`).

## Antes de la entrevista

Ten el proyecto instalado y arrancado antes de que empiece la sesión, con el editor y las herramientas de desarrollo del navegador a mano.

## Durante la entrevista

Se te pedirá revisar y mejorar `src/App.tsx`, explicando en voz alta lo que haces. Las instrucciones concretas se darán al inicio de la sesión.
